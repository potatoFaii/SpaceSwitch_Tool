# SpaceSwitch Tool for Autodesk Maya

## Overview
**SpaceSwitch** is a personal Maya tool inspired by the workflow and methodology shared by  
**Richard Lico** via [Animation Sherpa](https://www.animationsherpa.com/).

This script converts the concept into a practical tool for **personal use**, aimed at helping animators handle and mitigate **gimbal lock** issues during animation.

> ⚠️ This tool is intended for educational and personal use only.

---

## Features
- Avoid, fix, or *cheat* spaceSwitch issues in animation
- Designed to be lightweight and animator-friendly
- Integrates directly into Autodesk Maya via a shelf button
- Supports multiple rotation orders and workflow options

---

## Installation
1. Open **Autodesk Maya**
2. Drag and drop `SpaceSwitch_Install.mel` into the Maya viewport
3. A shelf icon will be automatically created
4. Click the icon to launch the tool

---

## Usage
- Select the target object(s)
- Adjust the available options as needed
- Run the tool to generate gimbal-safe locators and controls

*(Recommended for animation cleanup, complex rotations, and motion polishing.)*
